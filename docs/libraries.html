Other Libraries

The smaller libraries: Signal, RunService, IO, Process, Serde, Mouse, Keyboard, GPU, Voice, Managed.

Signal

Event objects with typed payloads. Engine-emitted signals fire on you; you can also build your own via Signal.new(). 

local Signal = import("Signal")
local hit = Signal.new()           -- Signal<...>

local conn = hit:Connect(function(damage, source) ... end)
hit:Fire(25, "fireball")
conn:Disconnect()
signal:Connect(fn)Subscribe. Returns a Connection.
signal:Once(fn)Fires at most once and auto-disconnects.
signal:Wait()Block the current coroutine until the next fire; return its args.
signal:Fire(...)Manual fire (only meaningful for user-created signals).
signal:DisconnectAll()Drop every connection at once.

Connection

Returned by :Connect() and :Once(). Hold it if you ever need to disconnect; otherwise let it live as long as the signal does.

.Connectedboolean — true until :Disconnect() is called or the signal is GC'd.
conn:Disconnect()Stop receiving fires. Idempotent.

RunService

The two per-frame heartbeats. Each fires once per heart tick (~60 Hz) with the elapsed dt.

RunService.HeartbeatSignal<number> — gameplay tick.
RunService.RenderSteppedSignal<number> — fires inside the render pump, slightly later in the frame than Heartbeat. Use for camera updates that need to land after gameplay state has finalised.
 
local RunService = import("RunService")
RunService.Heartbeat:Connect(function(dt)
    player:Update(dt)
end)

IO

File I/O. One-shot helpers for the common case; IO.open for streaming. Paths are interpreted relative to Ruzit's current root unless absolute.

One-shot helpers

IO.read(path)→ string. Throws if the file can't be opened.
IO.write(path, content)Truncate-write. Creates the file if missing.
IO.append(path, content)Append without truncating.
IO.exists(path)→ boolean. File OR directory.
IO.remove(path)Delete a file. No-op if absent; throws on permission errors.
IO.mkdir(path)Recursively create the directory chain.
IO.list(path)→ { string }. Names only, OS-defined order.
IO.getpath(path)Resolve a relative path to absolute.

IO.open

IO.open(path, mode?) → IOHandle

mode follows fopen conventions: "r" read, "w" truncate-write, "a" append, plus "+" variants. Default "r".

handle:read(format?)"*a" all (default), "*l" one line, "*L" line + newline, "*n" a number, or N bytes.
handle:write(content)Append at current position.
handle:close()Idempotent.
handle:path()Normalised path that was passed to IO.open.

.Os"windows" / "linux" / "macos" / "freebsd" / etc.

Methods

Serde

Encode/decode JSON / TOML / YAML, hash, and compress. All synchronous.

Serde.Encode(format, data, pretty?)format = "json" / "toml" / "yaml". Sequential 1-based tables become arrays.
Serde.Decode(format, text)Inverse.
Serde.Hash(algo, data, encoding?)algo: md5 / sha1 / sha224 / sha256 / sha384 / sha512 / sha3-256 / sha3-512 / keccak256 / blake3. encoding: hex (default) / base64 / bytes.
Serde.Compress(algo, data, level?)algo: gzip / zlib / deflate / zstd.
Serde.Decompress(algo, data)

GPU

Adapter info, frame stats, raycasting against the 3D scene, and storage-buffer plumbing for shaders.

Adapter / frame info

GPU.Info()→ GPUInfo — Name, Vendor, VendorID, DeviceID, Backend, Driver, DriverInfo, DeviceType.
GPU.Limits()→ GPULimits — MaxBufferSize and other wgpu hard limits.
GPU.FrameStats()→ GPUFrameStats — FPS, frame time, scene part count.

Raycasting

GPU.Raycast(origin, direction, filter?, maxDistance?) → RaycastHit?

CPU-side ray test against every renderable BasePart. Cubes and models test as oriented bounding boxes; spheres as ellipsoids. Hits are visited nearest-first; filter returns true to accept or false to skip.

GPU.ScreenToRay(point) → (Vector, Vector)

Screen pixel to world ray. Feed straight into Raycast.

GPU.WorldToScreen(world) → (Dim?, boolean)

Project a world point. (Dim, false) when in front of the camera; (nil, true) when behind the near plane.

Storage buffers

GPU.NewBuffer(size)→ GPUBuffer — size floats. Read-only inside shaders, available as SDATA: array<f32> at @group(0) @binding(4).
GPU.SetBuffer(buf)Bind as the active SDATA storage.
GPU.ClearBuffer()Unbind. SDATA reverts to a 1-float stub.
buf:Size()Slot count (in floats).
buf:Write(offset, values)Write a list of floats at offset. Bounds-checked.
buf:Fill(value)Fill the entire buffer with one number.

RaycastHit

Returned by GPU.Raycast. All vectors are world-space.

PartBasePart — the part the ray hit.
PositionVector — world-space hit point.
Distancenumber — world-space length from the ray's origin.
NormalVector — surface normal at the hit, in world space.

GPUInfo

Static adapter info, filled once at window-open time. Returned by GPU.Info().

NameDriver-reported display name (e.g. "NVIDIA GeForce RTX 4070").
VendorFriendly label: "NVIDIA" / "AMD" / "Intel" / "Apple" / "ARM" / "Qualcomm" / "Imagination" / "Microsoft" / "Other" / "Unknown".
VendorIDRaw PCI vendor id.
DeviceIDRaw PCI device id.
BackendGraphics backend wgpu chose: "Dx12" / "Vulkan" / "Metal" / "Gl" / "BrowserWebGpu".
DriverDriver version string, free-form.
DriverInfoExtra driver detail (build, date, etc.) — may be empty.
DeviceType"DiscreteGpu" / "IntegratedGpu" / "VirtualGpu" / "Cpu" / "Other". Useful for picking quality presets at startup.

GPULimits

Hard caps reported by the wgpu device. Returned by GPU.Limits().

MaxTextureSizeLargest 2D texture dimension (e.g. 16384 on most GPUs).
MaxBufferSizeLargest single buffer allocation in bytes. Closest stand-in for "VRAM per allocation".
MaxBindGroupsSimultaneously bound bind groups per pipeline.
MaxVertexBuffersVertex buffers per pipeline.
MaxComputeWorkgroup{ X, Y, Z } — compute workgroup size per axis.

GPUFrameStats

Live frame stats. Smoothed dt is an EMA so FPS doesn't strobe. Returned by GPU.FrameStats().

FPSSmoothed frames-per-second.
FrameTimeSmoothed frame time in seconds.
FrameCountTotal frames drawn since process start.
UptimeWall-clock seconds since GPU tracking started.
PartCountLive count of renderable parts in the scene.

Voice

Microphone capture + per-peer playback. Opus-encoded 20 ms frames over your transport (Steam P2P, our Net library, anything).

Voice API

Voice.StartCapture()→ VoiceCapture — opens the default mic.
Voice.CreateChannel()→ VoiceChannel — one per remote speaker.
Voice.PlayPacket(packet, opts?)Fire-and-forget transient channel for one-off messages.
Voice.NewRecorder()→ VoiceRecorder
Voice.LoadRecording(serialized)→ VoiceRecording
Voice.Volume / Speed / Spatial / ...Shader factories, same shape as SFX's.

VoiceCapture

.OnPacketSignal<string> — one Opus frame ~50 times/second.
cap:Stop() / :IsActive()
cap:Pause() / :Resume() / :SetActive(on)Push-to-talk; mic stays open.
cap:SetThreshold(amplitude) / :GetThreshold()Voice activation. 0..1 peak amplitude; below the threshold drops.

VoiceChannel

.IsPlayingboolean — true while at least one packet is queued.
chan:Push(packet)Feed received Opus packets. Auto-clamps backlog to ~1 second.
chan:Play() / :Stop()After Stop, new packets queue silently until you Play again.
chan:ApplyShader(shader) / :ClearShaders()Stack Voice.Volume / Speed / Spatial.
chan:SetPosition(x?, y?, z?)Anchor playback to a static world point. Camera = listener. Pass nil to clear.
chan:SetSpatial(x?, y?, z?, falloff?)Same as above, with distance falloff in one call.

VoiceRecorder

Captures Opus packets into an in-memory buffer. Hook to a VoiceCapture.OnPacket signal (your own mic) or to packets you receive from peers — both are just opaque Opus frames.

rec:Push(packet)Append one Opus packet to the recorded stream.
rec:Clear()Drop everything captured so far.
rec:Length()→ number — total packet count.
rec:Duration()→ number — total recorded duration in seconds.
rec:Serialize()→ string — length-prefixed binary form. Save with IO.write or to Steam Cloud.
rec:ToRecording()→ VoiceRecording — snapshot the current packet list without serialising.

VoiceRecording

Immutable snapshot, either built from recorder:ToRecording() or loaded from a serialised buffer via Voice.LoadRecording(bytes).

rec:PacketCount()→ number
rec:Duration()→ number — seconds.
rec:PlayInto(channel, opts?) Stream the recording's packets into channel at original ~50 packets/second pacing. Returns immediately — playback is dripped by the heart pump. opts: { loop: boolean?, speed: 0.25..4.0? }.

VoiceShader

Built by the factories below. Stack on a channel via chan:ApplyShader(shader) for compound effects. Multiple channels can share the same shader instance.

Factories

Voice.Volume(factor)Linear gain. 1.0 unchanged, 0 silence, >1 boost.
Voice.Speed(factor)Time + pitch.
Voice.Spatial(x, y, z, falloff?)Anchor to a world point with distance falloff. Listener = active Renderable.Camera.
Voice.LowPass(freq)Biquad lowpass at the given Hz. Useful for "muffled radio" presets.
Voice.HighPass(freq)Biquad highpass.
Voice.Distortion(amount)Soft saturation. >1 hard-clips.
Voice.Echo(delay_ms, feedback?, mix?)Single-tap echo.
Voice.Reverb(mix?, decay?)Diffuse reverb.
