Serde

Serialization, hashing, and compression. JSON / TOML / YAML for textual formats; ten hash algorithms; four compression codecs. 

local Serde = import("Serde")

local json = Serde.Encode("json", { health = 100, name = "Eve" }, true)
local data = Serde.Decode("json", json)
print(Serde.Hash("sha256", json))

Encoding

Serde.Encode(format, data, pretty?) → string

Serialise Lua data to a textual format. pretty adds whitespace (default false). Tables with sequential 1-based integer keys become arrays; otherwise they become objects with stringified keys.

Serde.Decode(format, text) → any

Inverse of Encode. Returns nested tables / numbers / strings / booleans / nils. Throws on malformed input.

Supported formats: "json", "toml", "yaml".

Hashing

Serde.Hash(algo, data, encoding?) → string

Cryptographic hash. encoding controls the return form: "hex" (default), "base64", or "bytes" (raw binary string).

HashAlgo (string)

ValueNotes
"md5"128-bit. Broken for cryptographic use; fine for non-security checksums.
"sha1"160-bit. Also broken; use sha256 unless you need legacy compatibility.
"sha224"SHA-2, 224-bit.
"sha256"SHA-2, 256-bit. The safe default.
"sha384"SHA-2, 384-bit.
"sha512"SHA-2, 512-bit.
"sha3-256"SHA-3, 256-bit. Different design family from SHA-2.
"sha3-512"SHA-3, 512-bit.
"keccak256"Keccak (pre-NIST SHA-3 finalist). Used in Ethereum.
"blake3"Modern fast hash. Excellent throughput for asset checksums.

Compression

Serde.Compress(algo, data, level?) → string

level is 0–9 for gzip / zlib / deflate, 1–22 for zstd. Default is each codec's mid-level. Output is a binary string.

Serde.Decompress(algo, data) → string

Inverse. Throws on truncated / bad-magic data.

CompressAlgo (string)

ValueNotes
"gzip"Standard gzip wrapper around DEFLATE.
"zlib"zlib wrapper around DEFLATE (smaller header than gzip).
"deflate"Raw DEFLATE, no wrapper.
"zstd"Modern Facebook codec. Faster + smaller than gzip at most levels; use level 3 for runtime, level 19+ for ship-it bundling.
