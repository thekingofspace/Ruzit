Image

Pixel inspection and procedural noise for ImageAssets. Read color and alpha at a coordinate, summarize a sprite as a single representative color, derive a deterministic seed from pixel data, and build layered 2D noise fields that you can paint onto a DynImg. 

local Asset = import("Asset")
local Image = import("Image")

local sprite = Asset.GetAsset("Image:icons.logo")
print(Image.GetPredominantColor(sprite))   -- Color3 of the most common quantized bucket
print(Image.GetColorAt(sprite, 8, 8))      -- pixel at (8, 8)
print(Image.ToSeed(sprite))                -- deterministic integer seed
Coordinate system. 0-based, origin top-left, +Y down — same convention as the rest of the engine's pixel APIs (DynImg, GUI.Image). Out-of-bounds reads error rather than wrap or clamp.

Image API

Image.GetColorAt(image, x, y) -> Color3 method

Sample the pixel at (x, y) and return its R/G/B as a Color3 in 0..1. Errors if the coordinate is out of bounds. The alpha channel is discarded — use GetAlphaAt when you need it.

Image.GetAlphaAt(image, x, y) -> number method

Alpha at (x, y) in 0..1. Errors if out of bounds. Useful for hit-testing transparent edges of an icon or for using a sprite as an opacity mask.

Image.GetPredominantColor(image) -> Color3 method

Most-common color, quantized to a 4-bit-per-channel histogram (4096 bins) so the result is stable against antialiasing and dithering. Pixels with alpha < 8/255 are ignored, so transparent sprite backgrounds don't skew the count. Returns black if the image is fully transparent.

Image.AverageColor(image) -> Color3 method

Alpha-weighted mean color. Good for picking a tint / ambient color that matches a sprite. Fully-transparent pixels contribute nothing; pixels with partial alpha count proportionally. Returns black if the image is fully transparent.

Image.ToSeed(image) -> number method

FNV-1a 64-bit hash of the pixel buffer XOR'd with width/height, returned as a signed integer. Same image always produces the same seed; two visually-identical images with different dimensions produce different seeds. Pair with NoiseField:GenerateLayer to make procedurally-generated content that's keyed off a sprite (icon → matching terrain, portrait → matching cloth pattern, etc.).

Image.Noise(width, height, fill?) -> NoiseField method

Allocate a width × height grayscale field, initialized to fill (default 0). Max dimension is 8192 per side. The field is just floats; call :GenerateLayer{...} to fill it with noise, then :ToBytes() to hand it to DynImg.FromPixels.

NoiseField

A mutable 2D grid of floats. Multiple noise types stack via :GenerateLayer{...} with a per-layer Mode so you can add detail, multiply a mask, take the max of two patterns, etc. Internally the buffer is just width × height floats; nothing is rendered until you read it back out with :ToBytes(), :GetValueAt, or :GetColorAt.

field:Width() -> number method

Pixel width of the field.

field:Height() -> number method

Pixel height of the field.

field:Clear(fill?) method

Reset every cell to fill (default 0). Cheap, just memsets — no realloc.

field:Fill(value) method

Same as :Clear(value) but the argument is required. Reads more naturally for non-zero fills.

field:GetValueAt(x, y) -> number method

Raw float at (x, y). Errors out of bounds. Range depends on what you've put in — fbm/value/perlin layers produce roughly 0..1; you can drive the field outside that range with Amplitude or Mode = "add" across many layers.

field:SetValueAt(x, y, value) method

Write a single cell. Useful for stamping in features by hand (e.g. carving rivers) after the noise layers generate the base.

field:GetColorAt(x, y) -> Color3 method

Clamp the cell to 0..1 and return it as a grayscale Color3. Convenience over GetValueAt when you want a color to pass into a tween / GUI / shader uniform without the manual wrap.

field:Normalize() method

Rescale the entire field so the min becomes 0 and the max becomes 1. Run this after stacking layers if you want the output to fit cleanly in a single DynImg byte. Flat fields (min == max) are zeroed.

field:ToBytes() -> string method

Pack the field into an RGBA byte string, width * height * 4 bytes. Each cell is clamped to 0..1, scaled to 0..255, written into R, G, and B (so the output is grayscale), with alpha forced to 255. Drop straight into DynImg.FromPixels(field:Width(), field:Height(), bytes).

field:GenerateLayer(params) method

Run a noise function over the whole field and combine it with what's already there. params is a table — see below for every option. Call it multiple times with different Type / Mode / Scale values to layer patterns.

GenerateLayer parameters

All fields are optional. Type and Mode are PascalCase by convention but the lower- case forms (type, scale, …) are also accepted for ergonomic config tables.

Field Values Default Effect
Type "fbm", "perlin" (alias "gradient"), "value", "ridged", "white" "fbm" Which noise function to evaluate. fbm is layered Perlin — the good default for terrain, clouds, marble, anything organic-looking. perlin / gradient is a single octave of classic Perlin. value is grid value noise — cheaper, blockier. ridged is fbm with 1 - |n| applied per octave, gives sharp ridges (good for mountains, lightning). white is uncorrelated noise per pixel — for static / film grain.
Mode "add", "set" (alias "replace"), "mul" (alias "multiply"), "max", "min" "add" How this layer combines with the current field value. The first layer typically uses "set" to overwrite the zero-fill; later layers usually "add" detail or "mul" a mask onto the result.
Scale number > 0 16 Feature size in pixels. Scale = 64 gives big slow blobs; Scale = 4 gives fine grain.
Amplitude number 1.0 Layer strength. Negative values invert the pattern. For "add" mode this is how much the layer contributes; for "set" / "mul" it scales the raw output.
Octaves 1..12 4 fbm/ridged only. Additional detail passes; each pass doubles the frequency (by Lacunarity) and halves the amplitude (by Persistence).
Lacunarity number > 1 2.0 fbm/ridged only. How much the frequency grows per octave. Higher = more chaotic, more high-frequency detail.
Persistence 0..1 0.5 fbm/ridged only. How much amplitude survives per octave. 0.5 is the canonical fbm taper; 0.7+ produces noisier output; 0.3 produces smoother output.
Seed integer 0 Deterministic — same seed always gives the same pattern. Use Image.ToSeed(asset) to derive one from a sprite.
OffsetX / OffsetY number 0 Pan the noise without changing the seed. Useful for infinite scrolling worlds (advance offsets per frame) or chunked terrain (offset = chunk * chunk_size).

Patterns

Pick a UI tint from a sprite

local Asset = import("Asset")
local Image = import("Image")
local GUI = import("GUI")

local icon = Asset.GetAsset("Image:icons.health")
local tint = Image.AverageColor(icon)

local bar = GUI.Basic.Square()
bar.Color = tint                       -- background color matches the icon

Sprite-seeded heightmap

local Asset = import("Asset")
local Image = import("Image")
local DynImg = import("DynImg")

local sprite = Asset.GetAsset("Image:flags.region_north")
local seed = Image.ToSeed(sprite)

local noise = Image.Noise(512, 512)
noise:GenerateLayer{ Type = "fbm",    Scale = 96, Octaves = 6, Seed = seed }
noise:GenerateLayer{ Type = "ridged", Scale = 32, Amplitude = 0.4, Seed = seed + 1 }
noise:Normalize()

local map = DynImg.FromPixels(noise:Width(), noise:Height(), noise:ToBytes())

Scrolling clouds

local Heart = import("Process").Heartbeat
local noise = Image.Noise(256, 256)
local tex = DynImg.FromPixels(256, 256, noise:ToBytes())
local t = 0

Heart:Connect(function(dt)
    t = t + dt * 12
    noise:Clear()
    noise:GenerateLayer{ Type = "fbm", Scale = 48, Octaves = 5, OffsetX = t }
    tex:SetPixels(noise:ToBytes())   -- DynImg writes the new frame
end)

Mask one layer with another

local n = Image.Noise(256, 256)

-- Base terrain.
n:GenerateLayer{ Type = "fbm", Mode = "set", Scale = 64, Seed = 1 }

-- Multiply by a soft circular mask so the edges fade out.
n:GenerateLayer{ Type = "perlin", Mode = "mul", Scale = 256, Seed = 2 }

-- Add sharp ridges only where there's already height (max-blend).
n:GenerateLayer{ Type = "ridged", Mode = "max", Scale = 16, Amplitude = 0.3, Seed = 3 }

n:Normalize()
Performance. Every :GenerateLayer{...} call evaluates the noise function once per pixel — a 512×512 fbm with 6 octaves is ~1.5M noise evaluations, ~5–15 ms on a modern CPU. Generating a tiny field (≤256²) every frame is fine; doing the same on a 4096² field is not. For animation, generate at low resolution and let the GPU's bilinear filter blow it up via a DynImg.
