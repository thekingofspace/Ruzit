Net

HTTP, TCP, UDP, IPC, and WebSockets. Synchronous APIs, if you need concurrency, run handlers through Actor. 

local Net = import("Net")

local res = Net.Request("GET", "https://example.com/api")
print(res.status, res.body)

HTTP

Net.Request(method, url, body?, headers?) → HttpResponse

Synchronous HTTP client. Throws on connection failure; non-2xx statuses come back via .status, not as exceptions.

Net.Serve(addr, handler)

Blocking HTTP server. The handler returns either an HttpResponse table or a plain string (wrapped as 200 OK text/plain).

HttpRequest / HttpResponse

HttpRequest.methodstring
HttpRequest.pathstring
HttpRequest.headers{ [string]: string }
HttpRequest.bodystring
HttpResponse.statusnumber
HttpResponse.headers{ [string]: string }
HttpResponse.bodystring

TCP

Net.TCP.Connect(addr) → TcpConnection

Dial a remote "host:port".

Net.TCP.Host(addr) → TcpListener

Bind + listen on a local "host:port". Pass :0 for an OS-assigned port.

TcpConnection

conn:Send(data)Block until the OS accepts the bytes.
conn:Receive(n?)Read up to n bytes (default 4096). "" on clean close.
conn:Close()Half-close. Subsequent Send/Receive throws.
conn:Peer()Remote "host:port".

TcpListener

lst:Accept()Block until a client connects.
lst:Close()Stop accepting. Existing connections keep working.
lst:Address()Local "host:port", useful when you bound to port 0.

UDP

Net.UDP.Bind(addr) → UdpHandle

Open a UDP socket on the given local "host:port". Pass :0 for an OS-assigned port; query it back with udp:Address().

udp:Send(addr, data)Returns bytes actually delivered to the OS.
udp:Receive(n?)Block for the next datagram. Returns (bytes, sender "host:port").
udp:Close()
udp:Address()Local "host:port".

IPC

Local-only stream over a Windows named pipe / Unix domain socket. Same semantics as TCP, restricted to the same machine. Pass a pipe/socket name, not a path; the OS-specific prefix is added for you.

Net.IPC.Connect(name) → IpcConnection

Dial a same-machine IPC endpoint. name is a bare pipe / socket name; the OS-specific prefix (\\.\pipe\ on Windows, /tmp/-style socket path on Unix) is added for you.

Net.IPC.Host(name) → IpcListener

Create a same-machine IPC server with the given name. Same prefix-handling rules as Connect.

WebSocket

Frame-oriented messaging. Each Send is one WebSocket message; Receive returns one full message (fragmentation handled for you).

Net.Socket.Connect(url) → WebSocketConn

Pass a ws:// or wss:// URL.

Net.Socket.Host(addr) → WebSocketListener

Pass "addr:port". TLS isn't auto-enabled on Host; terminate it in front of Ruzit.
