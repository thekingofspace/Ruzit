Managed

Runtime info about loaded .managed packages, the project itself, every DLC, and anything dropped into the Packages/ folder. Useful for game-side mod menus, "discovered DLC" overlays, and debug panels. 

local Managed = import("Managed")

for _, id in ipairs(Managed.List()) do
    local pkg = Managed.GetPackage(id)
    print(pkg.ID, pkg.Name, pkg.Version, tostring(#pkg:Files()) .. " files")
end

Managed API

Managed.IsPackage(id) → boolean

True if a package with this id is loaded.

Managed.GetPackage(id) → Package?

Look up a package by id. Returns nil if unknown.

Managed.List() → { string }

All loaded package ids, your own, every DLC, every Packages/ import.

Managed.Default() → Package?

The default (entry-point) package. In a built game this is the launcher's primary package; under ruzit test it's the project at the working directory.

Package

Returned by Managed.GetPackage and Managed.Default.

Properties

.IDstringread-only

Used in @PkgId/... cross-package references.

.Namestringread-only

Display name, build.toml's name or ManagedInfo.toml's name.

.Versionstringread-only

Free-form version string from the package's manifest.

.Creatorstringread-only
.Entrystringread-only

The entry script's vfs key (typically "Main.luau" or "init.luau").

.Originstringread-only

A vfs prefix you can pass to require ("@OtherPkg/sub/module"). For the calling package this is the empty string, use require(__dirname .. "/...") for self.

Methods

pkg:HasFile(key) → boolean method

True if the script with this vfs key exists in the package.

pkg:HasAsset(key) → boolean method

True if the asset key exists in the package.

pkg:Files() → { string } method

List every script's vfs key. Useful for editors / debug overlays / build-step linters.

pkg:Assets() → { string } method

List every asset key.
