GUI

2D overlay primitives, post-processing, and skybox shaders. Everything drawn over the 3D scene lives here. 

local GUI = import("GUI")
local Dim = import("Primitives").Dim

local hp = GUI.Basic.Square()
hp.Size     = Dim.new(200, 12)
hp.Position = Dim.new(24, 24)
hp.Color    = Color3.FromHex("#9bd13b")

GUI.Basic, primitive factories

GUI.Basic.Square() → Primitive

Solid-coloured rectangle. Tinted by .Color; sized by .Size.

GUI.Basic.Circle() → Primitive

Solid-coloured circle inscribed in .Size. The major axis follows the longer of .Size.X and .Size.Y, pass equal width / height for a true circle.

GUI.Basic.Triangle() → Primitive

Solid-coloured triangle inscribed in .Size: apex at top-center, base on the bottom edge. Useful for arrows / indicators, rotate via a custom shader if you need arbitrary orientations.

GUI.Basic.Image(asset) → Primitive

Textured rectangle. Pass an ImageAsset; the asset's pixels become the surface.

GUI.Basic.Font(asset) → Primitive

Text label. Pass a FontAsset; glyphs are rasterised at runtime sized by .TextSize.

Worked example: damage flash

local grade = GUI.SetPostEffect(Asset.GetAsset("Fragment", "damage.frag"))
grade:SetData("strength", 0.0)

function on_player_hit()
    local Process = import("Process")
    local elapsed = 0
    local conn
    conn = Process.Heartbeat:Connect(function(dt)
        elapsed += dt
        local t = elapsed / 0.4
        if t >= 1 then
            grade:SetData("strength", 0)
            conn:Disconnect()
        else
            grade:SetData("strength", 1 - t)
        end
    end)
end

DrawableImg & CanvasBuffer

DrawableImg is a CPU-mutable image you can draw to with primitive shapes. It exposes the same accessors as ImageAsset (Width, Height, Source, Pixels) and is accepted directly on a part's .Texture; mutating the drawable updates the texture on the next frame.

CanvasBuffer is a scratch buffer with the same draw methods, but mutations stay local until you :Apply them to a DrawableImg. Use it when you want to rebuild a sprite over many draw calls without triggering a per-call texture re-upload.

Coordinate convention: top-left is (0, 0), x increases right, y increases down. All coordinates are integer pixels; out-of-bounds pixels are clipped silently. Drawing methods alpha-blend over existing content; Fill and Clear overwrite without blending.

Factories

GUI.DrawableImg(width, height) → DrawableImg

Build a fresh, fixed-size mutable image. Pixels start at (0, 0, 0, 0) (transparent black). Not cached: each call returns a new instance with its own buffer.

GUI.CanvasBuffer(width, height) → CanvasBuffer

Build a scratch buffer of the given size. Has the same draw methods as DrawableImg, but you commit its contents to a real drawable via buffer:Apply(target, x, y).

Drawing methods (both DrawableImg and CanvasBuffer)

obj:WritePixel(x, y, color, transparency?)

Set a single pixel directly — overwrites, doesn't blend. Default transparency 0 (opaque).

obj:DrawRect(x, y, w, h, color, transparency?)

Alpha-blend a filled rectangle. :DrawCube is a synonym.

obj:DrawLine(x0, y0, x1, y1, color, transparency?)

Bresenham line, alpha-blended.

obj:DrawCircle(cx, cy, radius, color, transparency?, filled?)

Outline circle by default. Pass filled = true for a solid disc.

obj:Fill(color, transparency?)

Overwrite every pixel with one color + alpha. Doesn't blend.

obj:Clear()

Reset every pixel to (0, 0, 0, 0).

DrawableImg-only methods

img:Width()→ number
img:Height()→ number
img:Source()→ string

Origin label, "<drawable:WxH>". Mirrors ImageAsset:Source.

img:Pixels()→ string

Snapshot of the current RGBA8 buffer (Width * Height * 4 bytes). Useful for inspection or hand-rolled image processing.

img:IsAlive()→ boolean
img:Apply(buffer, atX?, atY?)

Convenience: alpha-blend a CanvasBuffer onto this drawable at the given offset. Equivalent to buffer:Apply(img, atX, atY).

img:Destroy()

Mark the drawable dead and zero its pixels. Any part still using it as a Texture will see transparent black. Drop the Lua reference (and clear the part's Texture) to release the buffer.

CanvasBuffer-only methods

buffer:Width()→ number
buffer:Height()→ number
buffer:Pixels()→ string
buffer:Apply(target, atX?, atY?)

Alpha-blend the buffer onto the target DrawableImg at the given offset (default (0, 0)). Bumps the drawable's version once, so the GPU re-upload happens in a single shot even though the buffer was mutated dozens of times.

Lifecycle

DrawableImgs are not cached (unlike Asset.GetAsset images). Every GUI.DrawableImg(...) call creates a fresh buffer. Once nothing references it, the Lua variable is gone and every consumer (parts using it as a Texture) has been cleared, the underlying buffer is freed; on the GPU side the renderer's eviction sweep drops the cached texture once no part references its id.

Worked example: paint a face onto a cube

local GUI = import("GUI")
local Renderable = import("Renderable")
local Color3 = import("Primitives").Color3

local face = GUI.DrawableImg(128, 128)
face:Fill(Color3.new(1, 0.9, 0.7))                            -- skin tone
face:DrawCircle(42, 48, 8, Color3.new(0, 0, 0), 0, true)    -- left eye
face:DrawCircle(86, 48, 8, Color3.new(0, 0, 0), 0, true)
face:DrawLine(40, 90, 88, 90, Color3.new(0.6, 0, 0))         -- mouth

local head = Renderable.BasePart("Cube")
head.Texture = face

-- Later: swap the eyes for a "blink" frame using a CanvasBuffer.
local blink = GUI.CanvasBuffer(128, 128)
blink:Fill(Color3.new(1, 0.9, 0.7))
blink:DrawLine(34, 48, 50, 48, Color3.new(0, 0, 0))
blink:DrawLine(78, 48, 94, 48, Color3.new(0, 0, 0))
blink:DrawLine(40, 90, 88, 90, Color3.new(0.6, 0, 0))
blink:Apply(face)                                              -- one re-upload
