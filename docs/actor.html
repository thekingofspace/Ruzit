Actor

Spawn worker pools that run Luau on other CPU cores. Each worker has its own isolated Luau state, jobs go in via Push, results come out via Pop. 

local Actor = import("Actor")

local fib = Actor.new([[
    local memo = {}
    return function(n)
        if memo[n] then return memo[n] end
        local a, b = 0, 1
        for _ = 2, n do a, b = b, a + b end
        memo[n] = b
        return b
    end
]])

for i = 1, 32 do fib:Push(i) end
while fib:Pending() > 0 do
    print(fib:Pop(true))
end

Actor API

Actor.new(source, threads?) → Actor

Create a worker pool. source must be a Luau source string whose chunk evaluates to a function, that function is what each worker invokes per Push. threads defaults to the CPU core count (1..256).

Actor.FromFile(path, threads?) → Actor

Load worker code from a separate .luau file. Path resolution mirrors require: relative, parent-relative, @PkgId/..., @self/....

Workers are isolated. They run in independent Luau states with no import / require / print / loadstring / __dirname, and can't touch the main thread's globals, GUI, assets, or sockets. Pass everything they need as arguments to Push.

Actor methods

actor:Push(...)method

Queue one job. Arguments are deep-copied to a worker.

actor:Pop(yield_for_result?)→ ...anymethod

Pop the next ready result. With yield_for_result = true blocks until one's available; without (default), returns nil immediately if nothing's ready. Order is first-to-finish, not Push order, work runs in parallel. Re-raises any error a worker hit.

actor:Pending()→ numbermethod

Number of jobs in flight + ready results not yet popped.

actor:Threads()→ numbermethod
actor:Close()method

Stop accepting jobs; workers exit when they finish their current call. Already-completed results stay drainable. Idempotent.

Patterns

Drain loop

while actor:Pending() > 0 do
    local r = actor:Pop()
    if r ~= nil then
        process(r)
    end
end

Sized pool for concurrent HTTP requests

local fetch = Actor.new([[
    return function(url)
        return url, tostring(os.time())
    end
]], 8)

for _, url in ipairs(targets) do fetch:Push(url) end
while fetch:Pending() > 0 do
    local url, ts = fetch:Pop(true)
    print(url, ts)
end
fetch:Close()
