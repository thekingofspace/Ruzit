Mouse

Cursor position, button state, scroll, lock + visibility, and the cursor sprite. Reads are cheap snapshots; signals fire from the engine event pump. 

local Mouse = import("Mouse")

Mouse.Moved:Connect(function(pos, delta)
    aim:RotateBy(delta.X * 0.1, delta.Y * 0.1)
end)
Mouse.InputReceived:Connect(function(button, state)
    if button == "MouseButton1" and state == "Begin" then
        fire_weapon()
    end
end)

Mouse API

Properties

.PositionDimread-only

Cursor position in window-local pixels. Origin top-left, +Y down.

.Visibleboolean

Whether the cursor sprite is shown.

.Lockedboolean

When true, the cursor is recentered every frame. Combine with .Visible = false for FPS-style mouselook.

.CursorCursorName

Active cursor sprite. See CursorName below.

Signals

.MovedSignal<Dim, Dim>read-only

Fires with (position, delta), both Dim. Delta is the per-frame movement; position is absolute window-local coords.

.InputReceivedSignal<MouseButton, "Begin" | "End">read-only

Fires with (button, state). state is "Begin" on press and "End" on release. See Deprecated below if you're migrating from a pre-3.2 codebase.

.ScrolledSignal<number, number>read-only

Fires with (deltaX, deltaY) in lines (one notch of a standard wheel = ±1). +deltaY is scroll up / away from the user; +deltaX is scroll right. Precise touchpads emit fractional values.

Methods

Mouse:SetCursor(name)method

Same as assigning Mouse.Cursor.

Mouse:Lock()method

Lock the cursor to the window center every frame.

Mouse:Unlock()method
Mouse:IsButtonDown(button)-> booleanmethod

Snapshot whether a button is currently held. Cheaper than tracking InputReceived state yourself.

MouseButton (string)

"MouseButton1"Primary (left).
"MouseButton2"Secondary (right).
"MouseButton3"Middle / wheel click.
"MouseButton4"Back (extra 1).
"MouseButton5"Forward (extra 2).

Deprecated

APIs removed or changed since the older shape. Code written against pre-3.2 docs goes here.

Pre-3.2: InputReceived with pressed boolean

Older versions fired InputReceived with the legacy (button, pressed, state) signature, a boolean duplicating the state string. As of Ruzit 3.2 the boolean is gone. Any version 3.2 or newer fires (button, state) only.

Pre-3.23.2+
 
Mouse.InputReceived:Connect(function(button, pressed)
    if pressed then fire_weapon() end
end)
 
Mouse.InputReceived:Connect(function(button, state)
    if state == "Begin" then fire_weapon() end
end)
Migration note. The boolean was the second argument; the State string took its place. A connect-side find/replace works: replace (button, pressed) with (button, state) and pressed / not pressed with state == "Begin" / state == "End".
