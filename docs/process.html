Process

Info about the running process: OS / arch, PID, env vars, command-line arguments, memory usage. Plus a heart-tick subscriber that runs even without a window open. 

local Process = import("Process")

print(Process.Os, Process.Arch, Process.CpuCount)
if not Process.IsBuilt then show_dev_overlay() end

Static fields

.Osstringread-only

"windows" / "linux" / "macos" / "freebsd" / etc. Match against this to gate platform-specific code paths.

.Archstringread-only

"x86_64" / "aarch64" / etc.

.Familystringread-only

"windows" / "unix" / "wasm".

.Pidnumberread-only

OS-assigned process id.

.CpuCountnumberread-only

Logical CPU count (hyperthreads included). Useful for sizing Actor pools or work batches.

.IsBuiltbooleanread-only

True when running from a built game launcher (.exe + Managed/); false under ruzit test. Gate dev-only debug overlays etc. behind this (or behind InTest, which is exactly the inverse).

.InTestbooleanread-only

Inverse of IsBuilt, true while running via ruzit test. Reads naturally for guards like if Process.InTest then ... end.

Heartbeat signals

Per-frame signals merged in from the old RunService import as of v3.3. Both fire once per heart tick (~60 Hz) with the elapsed dt in seconds. 

Process.Heartbeat:Connect(function(dt)
    player:Update(dt)
end)

Process.RenderStepped:Connect(function(dt)
    camera:FollowPlayer(player.Position, dt)
end)
.HeartbeatSignal<number>read-only

Gameplay tick. Fires before the render pump, use it for simulation logic that produces the state the renderer reads this frame. Payload is dt in seconds.

.RenderSteppedSignal<number>read-only

Same dt, but fires inside the render pump (slightly later in the frame than Heartbeat). Use it for camera updates and visual smoothing that need to land after gameplay state has finalised.

Frame ordering

Each frame the engine runs:

  1. Window / input / SFX / Steam / VR / Gamepad event pumps.
  2. Heartbeat, gameplay scripts.
  3. Animation track tick.
  4. RenderStepped, camera, post-effects, UI binds.
  5. GPU submit + present.
  6. Sleep until the next ~16.7 ms tick.

Putting camera follow in RenderStepped means it sees the player's final position for this frame, not last frame's. Doing it in Heartbeat would give you a one- frame lag.

Headless ticks. These signals only fire while a window is open. For background tasks that need to keep running with no window, use BindToHeart.

Environment

Process.Env(name) → string?

Read one variable. nil if unset. 

Process.Env("PATH")   -- "/usr/local/bin:/usr/bin:..."
Process.Env("NOPE")   -- nil
Process.Env() → { [string]: string }

Whole environment as a Lua table.

Process.SetEnv(name, value)

Set on the running process and inherited children. Doesn't persist beyond process lifetime.

Lifecycle

Process.Args() → { string }

argv passed to Ruzit (or the launcher), with element [1] being the executable name.

Process.Close(code?) → never

Hard-exit. code defaults to 0. Doesn't run BindToClose callbacks, use Window:Close for graceful shutdown when you have a window open.

Process.Memory() → MemorySnapshot

Snapshot of system memory. See below.

Heart-tick binding

For most per-frame logic prefer Process.Heartbeat , it's typed and connected to the same tick. BindToHeart is for background tasks that need to run even when no window is open (headless tools, Net.Serve event loops, etc.).

Process.BindToHeart(id, fn)

Subscribe a function to the engine heart tick. id is your own string label, used as the de-dup key (registering the same id twice replaces the old fn) and later for unbinding. The callback gets dt (seconds since the previous tick).

Process.UnbindFromHeart(id)

Remove a previously-bound callback. id is the same string label passed to BindToHeart. No-op if no callback with that id is registered.

MemorySnapshot

Returned by Process.Memory(). All fields in bytes.

totalTotal physical RAM.
freeStrictly currently-unallocated RAM. Typically much smaller than available.
usedtotal - free.
availableWhat the OS is willing to give a new allocation (may include reclaimable cache).
total_swapTotal swap space.
used_swapSwap currently in use.
