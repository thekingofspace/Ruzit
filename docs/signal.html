Signal

Event objects with typed payloads. Engine-emitted signals fire on you; you can also build your own via Signal.new(). Generic over the callback's argument types, LSP infers what your handler receives. 

local Signal = import("Signal")

local hit = Signal.new()           -- Signal<...>
local conn = hit:Connect(function(damage, source) print(damage, source) end)
hit:Fire(25, "fireball")
conn:Disconnect()

Signal API

Signal.new() → Signal<T...>

Construct a new user-emitable signal. The first :Fire(...) pins the type parameter pack T...; subsequent connects and fires are type-checked against it.

Signal<T...>

Generic-parameterized table type. Engine signals carry a fixed payload shape (e.g. Window.Changed is Signal<string>); user-created signals start unconstrained and pin on first fire.

signal:Connect(fn) → Connection method

Subscribe a callback. Returns a Connection , keep it if you ever need to disconnect; otherwise let it live as long as the signal does.

signal:Once(fn) → Connection method

Like Connect, but fires at most once and auto-disconnects.

signal:Wait() → T... method

Block the current coroutine until the next fire, then return its arguments.

signal:Fire(...) method

Manually fire. Most engine-provided signals are one-way (they fire on you, not from you), but signals built with Signal.new() let you fire freely.

signal:DisconnectAll() method

Drop every connection at once.

Connection

Returned by :Connect() and :Once().

.Connected boolean read-only

True until :Disconnect() is called or the signal is garbage-collected.

conn:Disconnect() method

Stop receiving fires. Idempotent.

Patterns

Subscribe-then-cleanup

local conn = win.Changed:Connect(function(prop)
    if prop == "Size" then redraw_ui() end
end)

win:BindToClose(function() conn:Disconnect() end)

Once for one-shot loaders

asset_loaded:Once(function(asset)
    show_splash(asset)
end)

Wait inside a coroutine

local Heart = import("Process").Heartbeat
for _ = 1, 60 do
    local dt = Heart:Wait()    -- one frame
    accumulated = accumulated + dt
end
