Debug

In-test profiler. Flag spans for timing, memory and CPU readouts, frame-drop monitoring, GPU submit timings. All methods become silent no-ops in a built game (when Debug.IsTest is false), so leaving Debug calls in shipped code is safe. 

local Debug = import("Debug")

local level = Debug.Flag("level-load")
level:Begin()
load_the_level()
local r = level:End()
print("loaded in ", r.ms, "ms; mem +", r.mem_delta_mb, "MB")

Debug.MonitorFrameDrops(35):Connect(function(dt_ms)
    print("frame drop: ", dt_ms, "ms")
end)

Debug API

Debug.IsTest boolean read-only

True under ruzit test, false in a built game. All other Debug methods are no-ops when this is false. Profiling code can stay in your scripts without affecting shipped performance.

Debug.Flag(name) → DebugFlag

Allocate a named flag for measuring a span. The name shows up in the printed summary so you can grep the log. Repeated :Begin / :End pairs on the same flag work fine and overwrite the :Last snapshot.

Debug.Memory()→ number

Process resident memory in bytes (latest sample, refreshed every ~500 ms by the sampler thread).

Debug.MemoryMB()→ number
Debug.CpuPercent()→ number

Process CPU usage as a percentage. Sysinfo reports this as a sum across logical cores, so a fully busy 8-core process can read up to 800.

Debug.FrameDrops()→ number

Total frame drops the heart loop has flagged since process start. A frame drop is a tick whose total time exceeded SetFrameDropThreshold (default 25 ms).

Debug.PeakFrameMs()→ number

Largest single-frame time in milliseconds since the last ResetPeak. Useful for spike hunting.

Debug.ResetPeak()
Debug.SetFrameDropThreshold(ms)

Frames longer than this count as a drop and feed FrameDrops / MonitorFrameDrops. Default 25 (≈ a missed 60 Hz tick).

Debug.MonitorFrameDrops(threshold_ms?) → Signal<number>

Subscribe to frame-drop events. The Signal fires once per dropped frame with the frame's total time in milliseconds. If threshold_ms is omitted, uses the global SetFrameDropThreshold value.

Debug.GpuSubmitAvgMs()→ number

Average milliseconds spent in queue.submit since the last ResetGpuStats. A cheap proxy for GPU pressure, true GPU utilization needs platform- specific APIs.

Debug.ResetGpuStats()

DebugFlag

Returned by Debug.Flag(name). A flag is a named span you can re-use, every :Begin / :End pair captures a fresh delta on the same flag.

flag:Begin()method

Snapshot baseline (time, memory, frame-drop count, GPU submit count).

flag:End() → table method

Return a delta report { name, ms, mem_delta_mb, cpu_pct, frame_drops, gpu_avg_ms } and print a one-line summary to stdout. Errors if :Begin wasn't called first.

flag:Last()→ tablemethod

The most recent { last_ms, last_mem_delta_mb, last_frame_drops }. Empty until the first :End.

flag:Name()→ stringmethod
Idle, never blocks. The sampler runs on a dedicated thread that calls into sysinfo every ~500 ms. The main loop never waits on it, calls like Debug.MemoryMB() read an atomic snapshot. Flags cost a single timestamp + counter read on Begin/End, so you can sprinkle them generously without measurable overhead.
