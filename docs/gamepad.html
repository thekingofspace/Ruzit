Gamepad

Native controller support via gilrs, XInput / DirectInput / udev / IOKit / SDL2 wrapped behind one Lua API. Layout names are normalised across vendors so the same code works for Xbox, PlayStation, and Switch pads. 

local Gamepad = import("Gamepad")

Gamepad.Connected:Connect(function(id) print("pad " .. id .. " connected") end)

Gamepad.InputChanged:Connect(function(ev)
    if ev.Kind == "Button" and ev.Name == "South" and ev.State == "Begin" then
        Gamepad.Vibrate(ev.Pad, 0.5, 0.1)   -- 100ms half-strength buzz
    end
end)

Gamepad API

Gamepad.GetGamepads() → { GamepadInfo }

Enumerate connected pads. Cheap (cached state), safe from a settings UI per frame.

Gamepad.IsButtonDown(pad, name) → boolean

Snapshot of whether name is currently held on the given pad. Cheaper than tracking InputChanged state yourself.

Gamepad.GetAxis(pad, name) → number

Current axis value: -1..1 for stick X/Y, 0..1 for triggers. Returns 0 if the pad disconnected or the name is unknown.

Gamepad.GetBatteryLevel(pad) → number?

0..1 charge level, or nil for wired pads / generic HID gamepads.

Force feedback

Gamepad.SetVibration(pad, low, high, duration) → boolean

low drives the strong / low-frequency motor (rumble), high drives the weak / high-frequency motor (buzz). Both 0..1; duration in seconds. Returns true when the rumble was actually scheduled, XInput pads on Windows always support FF; Bluetooth-paired controllers and most pads outside Windows often don't.

Gamepad.Vibrate(pad, intensity, duration) → boolean

Convenience: drives both motors at the same intensity.

Gamepad.StopVibration(pad?)

Cancel pending rumble. The pad argument is accepted for symmetry but ignored, gilrs only tracks effects globally.

GamepadInputEvent

Padnumber, pad id.
Kind"Button" · "Analog" · "Axis"
NameButton / axis name from the table above.
Value0 or 1 for digital buttons; 0..1 for analog triggers; -1..1 for stick axes.
State"Begin" on press / trigger crossing 0.5; "End" on release / trigger falling below 0.5; "Change" for axis updates.
